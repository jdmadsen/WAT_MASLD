# WAT_MASLD

Data analysis from: *Adipose tissue cell states linked to progression and clinical subtypes of MASLD in human obesity* — Madsen, Dam *et al.*

**Preprint:** [bioRxiv](https://www.biorxiv.org/content/10.1101/2025.09.25.678284v1.full)

All publicly available files for this project are hosted on the **Open Science Framework (OSF)** under the project **WAT_MASLD**.  
You can access and download them here:  
[https://osf.io/kwfp3/overview](https://osf.io/kwfp3/overview)

For easier exploration, several datasets have also been made available through the **Single Cell Portal**:  
[https://singlecell.broadinstitute.org/single_cell/study/SCP3208/a-single-nucleus-atlas-linking-adipose-cell-populations-to-liver-dysfunction-in-human-obesity?cluster=seurat_scp_coords.txt&spatialGroups=--&annotation=Annotation--group--study&subsample=all](https://singlecell.broadinstitute.org/single_cell/study/SCP3208/a-single-nucleus-atlas-linking-adipose-cell-populations-to-liver-dysfunction-in-human-obesity?cluster=seurat_scp_coords.txt&spatialGroups=--&annotation=Annotation--group--study&subsample=all)
